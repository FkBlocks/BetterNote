## 更好的体验
- 极低的内存占用和磁盘占用
- 轻巧的同时有丰富的功能

## 更加的智能
- 写字体验超越普通白板
- **后台**智能批注，智能PPT助手

### 功能详细介绍
#### 白板功能
- 类希沃白板的UI布局，无痛过度
- **无限大画布**，支持**多人书写** + **多指手势操作**，操作无缝衔接
- 拥有智能的**墨迹纠正功能**，绘制几何图形不再困难
- 流畅的书写体验，精准的触控，提高课堂效率

#### 批注功能
- 进入后台后，带有**智能批注悬浮球**
- 批注悬浮球内置**白板的所有功能**
- 但**同时附带 PPT 助手**，提供PPT页面**批注记忆**，课堂随时翻回查看；PPT翻页助手，没有翻页笔的老师也能体验更好的触屏PPT

### 开发者已投入使用
- 开发者本人已经在自己的学校的一体机中中**安装**并**积极手机校内老师和用户的体验反馈**
